## 2. 유저 플로우

### F1. 검색 → 예약 (핵심 전환 플로우)
```
홈 검색바(목적지·날짜·인원) → [검색]
 → /golf/search?destination=…&checkIn=…&checkOut=…&golfers=…
   → 필터/정렬/지도 → 카드 [패키지 보기]
     → /golf/package/[id]
       → 옵션(박·라운드) 선택 → 인원 조정 → 티타임 선택(라운드별 전부)
         → [예약 가능 확인]  (티타임 미완료 시 비활성)
           → /golf/checkout  → ①패키지 확인 ②예약자 정보 ③결제
             → /golf/booking-complete
```

### F2. 비교
카드/상세의 [비교] 담기(최대 3) → 하단 CompareTray → `/golf/compare`(항목별 표, 차이 강조) → 상세로 이동.

### F3. 위시리스트
카드/상세 하트 토글 → `/golf/my-trips`의 **저장** 탭에 노출(localStorage 유지).

### F4. 맞춤 견적
즉시 확정이 아닌 상품 또는 [맞춤 견적 요청] → `/golf/build` 위저드 → 견적 접수(마이트립 **견적** 탭).

### F5. 콘텐츠 → 예약
홈 ‘골프 여행 이야기’ 또는 `/golf/story` → 아티클 → 하단 **‘이 이야기 속 여행’ 관련 패키지** → 상세/예약.

## 3. 페이지별 기능 명세

### 3.1 홈 `/golf`
- **A. 히어로 + 검색바**(`SearchBox` hero): 목적지(팝오버)·여행일정(듀얼 캘린더)·골퍼·라운드 → 검색.
- **B. 카테고리 칩**: 스테이앤플레이/올인클루시브/주말/럭셔리/단체/여성/가족/막판특가 → `?category=`.
- **C. 인기 골프 여행지**: 6개 목적지 카드(평균가·골프장 수·**추천 시즌 pill**) → `?destination=`.
- **D. 베스트 패키지**: 상위 8개 `PackageCard`.
- **E. 왜 오마이트립 골프텔인가**: 4개 밸류 카드.
- **F. 나만의 골프 여행 만들기 CTA** → `/golf/build`.
- **G. 골프 여행 이야기(블로그)**: 아티클 4개 카드 → `/golf/story/[slug]`, ‘이야기 전체 보기’.
- **H. 신뢰/후기/파트너**: 통계·후기 3개·파트너 로고.

### 3.2 검색 결과 `/golf/search`
- **컴팩트 검색바**(sticky): **URL 파라미터를 읽어 목적지·날짜·인원 프리필**(재검색 시 재동기화).
- **필터 사이드바**(`FilterControls`, sticky): 가격(1인 슬라이더) · 숙박(2~5박) · 라운드(2·3) · 호텔등급(4·5성) · 고객평점(9+·8+) · 식사(조식·올인클루시브) · 포함(올인클루시브/공항픽업/카트/캐디/무료취소/즉시확정/초보자친화/단체친화) · 골프장 이동시간(≤45분) · 특가. 초기화 버튼.
- **결과 헤더**: “{목적지} 골프 패키지 N개”, 목록/지도 토글, 정렬(추천·낮은가격·평점·인기·거리·할인율).
- **카드**(`PackageCard`): 이미지·뱃지(베스트/임박특가/올인클루시브)·위시·성급·평점·N박N라운드·코스명·포함아이콘·무료취소/즉시확정·정가/할인/판매가·비교·[패키지 보기]. 카드 하단 `<details>` **라운드 옵션 3개 비교**.
- **레이아웃**: `auto-fill minmax(280px,1fr)`로 폭에 따라 2~3열(화면 넘침 방지).
- **지도 뷰**: 가격 핀 프리뷰.
- **빈 결과**: “조건에 맞는 패키지가 없어요” + 필터 초기화.
- **모바일**: 하단 필터/정렬 바 + 바텀시트, CompareTray.

### 3.3 패키지 상세 `/golf/package/[id]`
- **브레드크럼** · **갤러리**(메인+썸네일 4, 클릭 시 모달, 키보드 접근) · **헤더**(성급·N박N라운드·즉시확정·평점·후기수·추천시즌).
- **섹션 바로가기 nav**(sticky): 포함사항·호텔정보·골프장정보·티타임·여행일정·예약조건·후기(앵커 점프, 오프셋 보정).
- **포함/불포함 사항**.
- **호텔 정보**: 체크인/아웃·객실타입·편의시설·지도 프리뷰.
- **골프장 정보**(`CourseInfoSection`, 라운드별 인라인 아코디언): 코스 소개·시그니처홀·코스정보(전장/코스레이팅/슬로프/그린스피드/잔디/개장)·**스코어카드(18홀, 접이)**·운영시간·**현지 결제 요금(국가별 통화)**·플레이 조건·팀 구성·시설·드레스코드.
- **티타임 선택**(`#tee`): **선택 옵션의 라운드 수만큼** 슬롯 생성(라운드별 골프장 순환). ‘n/N 라운드 선택’ 배지. **전 라운드 선택 전 예약 비활성**(즉시확정 상품). 매진 슬롯 비활성.
- **여행 일정**(`ItinerarySection`): **사진 포함 매거진형** 일자별 카드(도착/라운드/출발) — Day 배지·서술·식사칩(조식/중식/석식)·타임라인(시간·활동·태그)·하이라이트 팁.
- **예약 조건** · **후기**(호텔/골프장 탭, 평점 분해 바).
- **sticky 예약 카드**(aside): 1인가·옵션 select·골퍼/비골퍼 스텝퍼·박·라운드·티타임 선택 수·총액·[예약 가능 확인 / 맞춤 견적 요청]·숨은 비용 없음. **모바일 하단 고정 CTA**.

### 3.4 비교 `/golf/compare`
- 최대 3개, 항목별 표(가격·정가·할인·숙박·라운드·객실·골프장·조식·카트·캐디·픽업·올인클루시브·무료취소·즉시확정·평점·거리). **차이 나는 항목 강조**. 빈 상태 처리.

### 3.5 맞춤 견적 `/golf/build`
- 위저드로 목적지·기간·인원·선호를 입력 → 견적 요청 접수(프로토타입: 마이트립 견적 탭 반영).

### 3.6 체크아웃 `/golf/checkout`
- **3스텝**: ①패키지 확인(포함사항·숨은비용 없음) ②대표 예약자(이름·이메일 필수·연락처·국가) ③결제(카드/애플/구글/계좌 — UI). 우측 예약 요약(소계·세금·총액·취소정책). **필수 미입력 시 진행 비활성**. → 완료 페이지.
- ⚠️ 실 결제 없음(시뮬레이션). PG 연동은 [03 문서].

### 3.7 예약 완료 `/golf/booking-complete`
- 예약번호·요약·다음 안내. 마이트립 이동.

### 3.8 마이 트립 `/golf/my-trips`
- 탭: **예정 여행 · 지난 여행 · 저장(위시) · 견적**. 예약 카드(바우처/티타임/컨시어지 액션 — UI). 저장 탭은 위시리스트 연동.

### 3.9 블로그 `/golf/story`, `/golf/story/[slug]`
- 목록: 피처드 + 3열 카드. 상세: 히어로·본문(섹션 제목·문단·이미지·캡션)·태그·**관련 패키지 CTA**(목적지/태그 매칭)·다른 이야기.

## 4. 상태 · 로직 (전역/세션)

| 상태 | 저장 | 설명 |
|---|---|---|
| 통화(Currency) | localStorage `omg-currency` | USD/KRW/JPY/VND/EUR · `fx(usd)` 포맷(프로토타입 고정 환율) |
| 언어(Language) | localStorage `omg-language` | ko(기본)/en/ja/zh · `t(key)` UI 사전(`features/golf/i18n.ts`) |
| 위시리스트 | localStorage `omg-wishlist` | 패키지 id 배열 |
| 비교 | localStorage `omg-compare` | 최대 3개 |
| 최근 검색 목적지 | localStorage `omg-recent-golf` | 목적지 팝오버 ‘최근 검색’ 탭 |
| 검색 필터 | URL 쿼리 + 컴포넌트 state | `features/golf/search.ts`(parse/filter/sort) |
| 티타임 선택 | 컴포넌트 state | 라운드별 시간, 전 라운드 선택 시에만 예약 활성 |

**검증 규칙**
- 즉시확정 상품: 티타임 전 라운드 선택 전 예약 버튼 비활성.
- 체크아웃: 이름·이메일 필수.
- 비교: 4번째 담기 비활성(최대 3).

**환율·언어는 프로토타입 고정값** — 실환율 API/번역은 [03 문서].
