### 1.1 헤더 (2026-08 갱신)
- **로고 클러스터**: `OHMYTRIP` 워드마크(이미지) → **오마이트립 메인(`/`)**, 옆의 `골프텔` 배지 → **골프텔 홈(`/golf`)**. 로고 이미지 로드 실패 시 브랜드색 `OHMYTRIP` 텍스트로 폴백(깨진 아이콘 방지).
- **글로벌 내비(3개로 축소)**: 골프 패키지(`/golf/search`) · 특가(`/golf/search?deals=1`) · 맞춤 견적(`/golf/build`). ⇐ “오마이트립 안의 골프텔 = 단일 카테고리” 방향에 따라 메뉴 최소화.
- 우측: 언어·통화 드롭다운 · 위시(마이트립) · 로그인. 모바일: 햄버거 → 드로어(최상단에 ‘← 오마이트립’ 복귀 링크).

### 1.2 오마이트립 클론 진입점
- 오마이트립 메인 검색 패널 탭 순서: **호텔 · 골프텔(NEW) · 항공 · 액티비티 · 렌터카 · 항공+호텔**. 골프텔은 숙박 계열이라 **호텔 바로 옆**에 배치, 클릭 시 `/golf`.
- 격리 전환: 골프 진입 시 body 클래스 `omt-desktop → ohmygolf-body`, 로고로 복귀 시 `omt-desktop`으로 원복(검증됨).

## 2. 유저 플로우

### F1. 검색 → 예약 (핵심 전환 플로우)
```
오마이트립 메인 → [골프텔 탭] → /golf
홈 검색바(목적지·날짜·인원) → [검색]
 → /golf/search?destination=…&checkIn=…&checkOut=…&golfers=…
   → 필터(여성친화 시설 포함)/정렬/지도 → 카드 [패키지 보기]
     → /golf/package/[id]  (검색에서 고른 날짜를 그대로 사용)
       → 옵션(박·라운드) 선택 → 인원 프리셋/스텝퍼 → 조인·단독 선택
         → 티타임 선택(일자별·라운드별 전부) → (선택) 스테이 애드온
           → [예약 가능 확인]  (티타임 미완료 시 비활성)
             → /golf/checkout  → ①패키지 확인 ②예약자 정보 ③결제(애드온 합산)
               → /golf/booking-complete
```

### F2. 비교
카드/상세의 [비교] 담기(최대 3) → 하단 CompareTray → `/golf/compare`(항목별 표, 차이 강조) → 상세로 이동.

### F3. 위시리스트
카드/상세 하트 토글 → `/golf/my-trips`의 **저장** 탭에 노출(localStorage 유지).

### F4. 맞춤 견적
즉시 확정이 아닌 상품 또는 [맞춤 견적 요청] → `/golf/build` 위저드 → 견적 접수(마이트립 **견적** 탭).

### F5. 콘텐츠 → 예약
홈 ‘골프 여행 이야기’ 또는 `/golf/story` → 아티클 → 하단 **‘이 이야기 속 여행’ 관련 패키지** → 상세/예약.

## 3. 페이지별 기능 명세

### 3.1 홈 `/golf`
- **A. 히어로 + 검색바**(`SearchBox` hero): 목적지(팝오버)·여행일정(듀얼 캘린더)·골퍼·라운드 → 검색. 히어로 카피는 “자연 속 힐링 · 프리미엄 해외 골프 여행”(폭넓은 소구).
- **B. 카테고리 칩**: 여성/럭셔리/가족/스테이앤플레이/올인클루시브/주말/단체/막판특가 → `?category=` (여성·럭셔리·가족 우선 노출).
- **C. 인기 골프 여행지**: 6개 목적지 카드(평균가·골프장 수·**추천 시즌 pill**) → `?destination=`.
- **D. 추천/베스트 패키지**: 힐링 큐레이션(여성친화·자연 시설 우선) 상위 `PackageCard`.
- **E. 왜 오마이트립 골프텔인가**: 4개 밸류 카드(맞춤·자연 힐링 스테이·투명 올인 가격·여행 전문가 동행).
- **F. 나만의 골프 여행 만들기 CTA** → `/golf/build`.
- **G. 골프 여행 이야기(블로그)**: 아티클 4개 카드 → `/golf/story/[slug]`.
- **H. 신뢰/후기/파트너**: 통계·후기 3개(여성 골퍼 후기)·파트너 로고 · 시즌 배너 · 상담 FAB.

### 3.2 검색 결과 `/golf/search`
- **컴팩트 검색바**(sticky): **URL 파라미터를 읽어 목적지·날짜·인원 프리필**(재검색 시 재동기화).
- **필터 사이드바**(`FilterControls`, sticky) — **필터·정렬은 URL 쿼리에 동기화**(`serializeFilters`)되어 공유·새로고침 시 상태 유지:
  - **여성친화 시설**(상단 강조): 온천 · 스파·사우나 · 수영장 · 조·석식 포함 · 클럽하우스 근접
  - 가격(1인 슬라이더) · 숙박(2~5박) · 라운드(2·3) · 호텔등급(4·5성) · 고객평점(9+·8+) · 식사(조식·올인클루시브)
  - 포함(올인클루시브/공항픽업/카트/캐디/무료취소/즉시확정/초보자친화/단체친화) · 골프장 이동시간(≤45분) · 특가. 초기화 버튼.
- **결과 헤더**: “{목적지} 골프 패키지 N개”, 목록/지도 토글, 정렬(추천·낮은가격·평점·인기·거리·할인율).
- **카드**(`PackageCard`): 이미지·뱃지(베스트/임박특가/올인클루시브)·위시·성급·평점·N박N라운드·코스명·**골프 특화 태그**·포함아이콘·**요금 포함/현지결제 배지**·무료취소/즉시확정 · 하단 **2행 푸터**(가격 정보 전체폭[정가/할인/판매가·/1인·적립 포인트] → 아래 액션행[비교 · 패키지 보기]). *2행 구조로 긴 KRW 가격에서도 줄바꿈 없이 카드 높이 정렬.*
- **레이아웃**: `auto-fill minmax(280px,1fr)`로 폭에 따라 2~3열(화면 넘침 방지).
- **지도 뷰**: 가격 핀 프리뷰. **빈 결과**: 안내 + 필터 초기화. **모바일**: 하단 필터/정렬 바 + 바텀시트, CompareTray.

### 3.3 패키지 상세 `/golf/package/[id]`
- **브레드크럼** · **갤러리**(메인+썸네일, 모달·키보드 접근) · **헤더**(성급·N박N라운드·즉시확정·평점·후기수·추천시즌).
- **섹션 바로가기 nav**(sticky): 상품 소개·포함사항·호텔정보·골프장정보·티타임·여행일정·안심 케어·추가 옵션·후기(앵커 점프, 오프셋 보정).
- **상품 소개**(`packageIntro`): 국가·호텔·박/라운드·코스·시설·힐링/안심 포인트를 담은 서술 문단.
- **포함/불포함 사항** + **요금 포함/현지결제 배지**.
- **호텔 정보**: 체크인/아웃·객실타입·편의시설·지도 프리뷰.
- **골프장 정보**(`CourseInfoSection`, 라운드별 인라인 아코디언): 코스 소개·시그니처홀·코스정보(전장/레이팅/슬로프/그린스피드/잔디/개장)·**스코어카드(18홀, 접이)**·운영시간·**현지 결제 요금(국가별 통화)**·플레이 조건·팀 구성·시설·드레스코드.
- **티타임 선택**(`#tee`, 여행일정 위): **선택 옵션의 라운드 수만큼** 슬롯 생성, **일자별**(검색 체크인 기준 라운드별 날짜) · 라운드별 골프장 순환 · 시간대 그룹(새벽/오전/오후). ‘n/N 라운드 선택’ 배지. **전 라운드 선택 전 예약 비활성**(즉시확정 상품). 매진 슬롯 비활성. 날짜 변경은 캘린더로.
- **여행 일정**(`ItinerarySection`): **사진 포함 매거진형** 일자별 카드(도착/라운드/출발) — Day 배지·서술·식사칩·타임라인·하이라이트 팁.
- **안심 케어**(`#care`): 공항 전용 픽업 · 한국어 현지 지원 · 여성 캐디 요청 · 조인팀 안전 매칭 · 24시간 컨시어지(제공 여부 표시).
- **추가 옵션 / 스테이 애드온**(`#addons`, 넓은 카드 그리드): 스파&온천 바우처($40/1인) · 전신 아로마 마사지($30/1인) · 야시장 미식 투어($25/1인) · 프라이빗 픽업 업그레이드($20/팀). 각 카드에 설명·수량 담기.
- **예약 조건** · **후기**(호텔/골프장 탭, 평점 분해 바).
- **sticky 예약 카드**(aside): 포함 배지 · **1인 유효가**(effectivePerPerson) · 옵션 select · **인원 프리셋 행**(부부2인/친구4인/모임6인/혼골1인) · **조인/단독팀 선택** · 골퍼/비골퍼 스텝퍼 · 소인원 할증 안내 · 애드온 요약 · **‘패키지 합계’(세금 별도, 애드온 합산)** + ‘세금은 결제 시 계산’ 주석 · [예약 가능 확인 / 맞춤 견적 요청]. **모바일 하단 고정 CTA**. *(포인트 적립 표기는 현재 비활성)*

### 3.4 비교 `/golf/compare`
- 최대 3개, 항목별 표(가격·정가·할인·숙박·라운드·객실·골프장·조식·카트·캐디·픽업·올인클루시브·무료취소·즉시확정·평점·거리). **차이 나는 항목 강조**. 빈 상태 처리.

### 3.5 맞춤 견적 `/golf/build`
- 위저드로 목적지·기간·인원·선호를 입력 → 견적 요청 접수(프로토타입: 마이트립 견적 탭 반영).

### 3.6 체크아웃 `/golf/checkout`
- **3스텝**: ①패키지 확인(포함사항·**선택 애드온**·숨은비용 없음) ②대표 예약자(이름·이메일 필수·연락처·국가) ③결제(카드/애플/구글/계좌 — UI). 우측 예약 요약(패키지 소계 + **애드온 합산** + 세금 + **‘최종 결제액’**·취소정책). **필수 미입력 시 진행 비활성**. → 완료 페이지. *(포인트 사용/적립 표기는 현재 비활성)*
> **총액 라벨 구분**: 상세 예약카드=‘패키지 합계’(세금 별도), 체크아웃=‘최종 결제액’(세금 포함). 동일 상품의 두 화면 총액이 다른 이유(세금 유무)를 라벨로 명확화.
- ⚠️ 실 결제 없음(시뮬레이션). PG 연동은 [03 문서].

### 3.7 예약 완료 `/golf/booking-complete`
- 예약번호·요약·다음 안내. 마이트립 이동.

### 3.8 마이 트립 `/golf/my-trips`
- 탭: **예정 여행 · 지난 여행 · 저장(위시) · 견적**. 예약 카드(바우처/티타임/컨시어지 액션 — UI). 저장 탭은 위시리스트 연동.

### 3.9 블로그 `/golf/story`, `/golf/story/[slug]`
- 목록: 피처드 + 3열 카드. 상세: 히어로·본문(섹션 제목·문단·이미지·캡션)·태그·**관련 패키지 CTA**(목적지/태그 매칭)·다른 이야기.

## 4. 상태 · 로직 (전역/세션)

| 상태 | 저장 | 설명 |
|---|---|---|
| 통화(Currency) | localStorage `omg-currency` | USD/KRW/JPY/VND/EUR · `fx(usd)` 포맷(프로토타입 고정 환율) |
| 언어(Language) | localStorage `omg-language` | ko(기본)/en/ja/zh · `t(key)` UI 사전(`features/golf/i18n.ts`) |
| 위시리스트 | localStorage `omg-wishlist` | 패키지 id 배열 |
| 비교 | localStorage `omg-compare` | 최대 3개 |
| 최근 검색 목적지 | localStorage `omg-recent-golf` | 목적지 팝오버 ‘최근 검색’ 탭 |
| 검색 필터 | URL 쿼리 + 컴포넌트 state | `features/golf/search.ts`(parse/filter/sort, **wellness 포함**) |
| 옵션·인원·조인단독 | 컴포넌트 state | 박·라운드 옵션, 골퍼/비골퍼 수, 조인/단독(할증 계산) |
| 티타임 선택 | 컴포넌트 state | 일자별·라운드별 시간, 전 라운드 선택 시에만 예약 활성 |

**검증 규칙**
- 즉시확정 상품: 티타임 전 라운드 선택 전 예약 버튼 비활성.
- 체크아웃: 이름·이메일 필수.
- 비교: 4번째 담기 비활성(최대 3).
- 인원: 골퍼 ≥1; 소인원(≤3)·단독팀 선택 시 할증 안내 노출.

**가격 계산(프로토타입)**: `effectivePerPerson(base, golfers, soloTeam) = base × 소인원할증 × (단독팀 ? 1.15 : 1)`, 소인원할증 = 2인 1.2·3인 1.1·4인+ 1.0. 총액 = 유효 1인가 × 골퍼 + 비골퍼 요금 + 애드온 합산. **애드온**: ‘/1인’ 단위는 전체 인원(골퍼+비골퍼)만큼, ‘/팀’·‘/1회’는 1회 계산. 체크아웃 최종 결제액은 여기에 세금 10% 가산. **환율·할증률·비골퍼 요금은 프로토타입 가정값 — 정책 확정 필요([03·04 문서]).** *포인트 적립(`golfPoints`)은 계산 시드로만 보존하고 UI는 비활성(오마이호텔 포인트 미도입).*

**표시 그리드**: 홈 추천/베스트 패키지(`g-pkg-grid`)는 **1행 3개**(데스크톱) → 2개(태블릿) → 1개(모바일). 검색 결과는 사이드바 기준 3열.
