### 1.4 격리 & 오마이트립 통합
- `GolfShell`이 마운트 시 body 클래스 `omt-desktop/omt-mobile` 제거 → `ohmygolf-body` 부여, 언마운트 시 복원. 모든 골프 스타일 `.ohmygolf …` 스코프 → **OMT 클론과 상호 무간섭**(검증됨).
- **진입/복귀**: 오마이트립 메인 검색 패널 ‘골프텔’ 탭 → `/golf`; 골프 헤더 **OHMYTRIP 로고 → 메인(`/`)**, `골프텔` 배지 → 골프 홈. 왕복 시 body 클래스 전환 정상(검증됨).
- **로고 폴백**: 로고 이미지 로드 실패 시 브랜드색 `OHMYTRIP` 텍스트로 자동 대체 → 깨진 이미지 아이콘 방지.

## 3. 로드맵

### 벤치마크·리서치 반영 현황
- **GORA 벤치마크(완료)**: 골프 포인트·티타임 시간대 그룹·티타임 재고(mock)·홀별 사진·리뷰기반 추천·인기 랭킹·시그니처 컬렉션.
- **한국 골프여행사 7곳(완료·Top5)**: ①조인/단독 + 소인원 할증 ②그린피·카트·캐디·픽업 포함/현지결제 배지 ③카카오톡 상담 FAB ④골프 특화 태그 ⑤출발 요일 제한 + 신뢰 배지(관광사업자·통신판매업·IATA·여행자보험 3억).
- **여성 골퍼 트렌드 리서치(완료)**: 인원 프리셋(2~4인 여성·부부)·여성친화 시설 필터·안심 케어·스테이 애드온(스파/미식/마사지/픽업)·상품 소개.
- **타깃팅(완료)**: ‘30·40대 여성 자연 힐링 골프’ 컨셉 확립 후, 히어로 카피는 커플·친구·동호회까지 **폭넓게 확장**(세그먼트 과밀 → 유입 축소 방지). 세부 큐레이션·안심·필터는 여성 친화 유지.
- **오마이트립 클론 통합(완료)**: 메인 검색 패널 골프텔 탭 진입 ↔ 로고 메인 복귀.

## 4. 리스크 / 이슈

| 리스크 | 영향 | 대응 |
|---|---|---|
| 오프토픽 스톡 이미지 | 신뢰도·시연 인상 | 실사진 확보 전까지 큐레이션된 골프 이미지로 교체 |
| 정적 export vs 실시간 재고 | 티타임·가격 최신성 | CSR fetch 또는 SSR/ISR 전환 |
| 티타임 재고 트랜잭션 | 오버부킹 | 홀드/확정 로직 + 파트너 API SLA |
| 현지 결제 항목(카트/캐디) | 가격 오해·클레임 | 표기·정산 정책 확정, ‘현지 결제’ 명확 고지(반영됨) |
| **할증·비골퍼·적립률 가정값** | 가격/포인트 정확성 | 조인·단독·소인원 할증률, 비골퍼 요금, 적립률(2%) 정책 확정 |
| **애드온 정산·안심 케어 SLA** | 실행 가능성 | 부가상품 재고·수수료·현지 파트너 계약 필요 |
| 타깃 메시지 균형 | 유입 vs 차별화 | 히어로는 폭넓게, 큐레이션은 여성 친화(현 방향) — 성과 데이터로 재조정 |
| 콘텐츠 미번역 | 글로벌 사용성 | 상품/블로그 다국어화 |

1. **골프텔 카테고리 정식 채택 여부**
