## 2. 발견 이슈 / 결정 필요 (기획 판단)

| # | 이슈 | 상세 | 결정·조치 |
|---|---|---|---|
| **F1** | 애드온이 인원수에 안 곱해짐 | 스파 “$40 /1인”인데 4인 예약이어도 +$40만(정액 토글) | ✅ **조치**: ‘/1인’ 단위는 전체 인원(골퍼+비골퍼)만큼 자동 곱, ‘/팀’은 1회. 실측 검증(스파×2=$80, 픽업×1=$20) |
| **F2** | 신규 컴포넌트 다국어 미적용 | EN 전환 시 ‘여성친화 시설’ 필터 등이 한국어 | ⏸ **보류(결정)**: 국내 여성 골퍼 타깃 → 한국어 우선 유지. EN 완성은 실서비스화 단계 |
| **F3** | 총액 표기 불일치 | 상세 ‘총액’=세금 전, 체크아웃 ‘총액’=세금 포함 | ✅ **조치**: 라벨 구분 — 상세=‘패키지 합계’(+‘세금은 결제 시 계산’ 주석), 체크아웃=‘최종 결제액’ |
| **F4** | 필터 URL 미동기화 | 여성친화/정렬이 URL에 안 남음 | ✅ **조치**: 필터·정렬을 URL 쿼리에 동기화(`serializeFilters`). 새로고침·공유 시 상태 복원 실측 확인 |
| **F5** | 상세 섹션 nav에 ‘상품 소개’ 앵커 없음 | 상품소개 점프 링크 부재 | ✅ **조치**: `#intro` 앵커 + nav 최상단 ‘상품 소개’ 링크 추가 |

> F1·F3·F4·F5는 **수정·배포 완료**(tsc/lint/build 통과, 라이브 실측 검증). F2는 발주자 결정으로 보류.
