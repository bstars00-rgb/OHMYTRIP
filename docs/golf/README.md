## 2. 제품 개요

**무엇**: 숙박(골프텔) + 라운드(티타임)를 한 번에 예약하는 **Stay & Play 패키지** 상품. 오마이트립 본 서비스의 새 카테고리로 검토 중.

**타깃/포지셔닝**: **30·40대 여성 골퍼가 해외에서 자연 속 힐링과 라운드, 여행을 함께 즐긴다**는 컨셉. 단, 카피는 특정 인구통계로 좁히지 않고 커플·친구·동호회까지 아우르도록 확장(유입 축소 방지) — 화면 상단 메시지는 폭넓게, 큐레이션·안심 케어·시설 필터는 여성 친화로 차별화.

**왜 프로토타입 먼저**: 자사 시스템(ELLIS)에 골프텔 상품 공간이 아직 없어, 화면·플로우·데이터 구조를 **프론트로 먼저 검증**하고 방향성을 판단하기 위함.

**벤치마크**: Golfbreaks · golfscape · Your Golf Travel · monkeytravel(골프텔 상세 구조) · **GORA(일본 티타임 플랫폼)** · **한국 골프여행사 7곳**(조인/단독·포함배지·상담채널·신뢰배지) · **여성 골퍼 여행 트렌드 리서치**(프리셋·웰니스·안심).

**핵심 가치 제안**
1. 숙박·라운드·티타임·이동을 **1인당 투명 가격**으로 패키지화 (현장 추가 결제 최소화)
2. 골프장 상세 정보(스코어카드·현지요금·플레이 조건)를 **패키지 안에서** 제공 → 페이지 이동 없이 예약
3. 여성 골퍼 여정 배려: **인원 프리셋·여성친화 시설 필터·안심 케어·스테이 애드온(스파/미식/마사지/픽업)**
4. 콘텐츠(골프 여행 이야기) → 관련 패키지 CTA로 **읽다가 바로 예약**

## 3. 범위 (현재 프로토타입에 포함/미포함)

### ✅ 포함 (동작하는 프로토타입)
- 검색(목적지 팝오버·듀얼 캘린더·인원) → 결과(필터/정렬/지도) → 상세 → 예약 위저드 → 완료 → 마이트립
- 골프장 상세 정보(**패키지 내 인라인**), 사진 여행일정, 티타임 선택·검증, 비교(최대 3), 위시리스트, 맞춤 견적
- **여성 골퍼 UX(2026-08)**: 인원 프리셋(부부2인/친구4인/모임6인/혼골1인)·여성친화 시설 필터(온천/스파/수영장/식사/클럽하우스 근접)·안심 케어(픽업/한국어/여성캐디/조인매칭/컨시어지)·스테이 애드온(스파·마사지·미식·픽업)·상품 소개 문단
- **가격 로직**: 1인당 투명가 + 조인/단독팀 할증(+15%)·소인원 할증(2인 ×1.2·3인 ×1.1)·**오마이 골프 포인트 적립**·애드온 합산
- **GORA 벤치마크 UX**: 골프 포인트·티타임 시간대 그룹(새벽/오전/오후)·인기 골프텔 랭킹·시그니처 컬렉션
- **한국 골프여행사 Top5**: 조인/단독 + 할증 · 포함/현지결제 배지 · 카카오톡 상담 FAB · 골프 특화 태그 · 출발 요일 제한 + 신뢰 배지
- 통화 5종·언어 4종(UI), 골프 여행 이야기 블로그
- **오마이트립 클론 통합**: 메인 검색 패널 골프텔 탭 진입 ↔ 골프 헤더 로고로 메인 복귀(격리 전환 검증)
- 반응형(데스크톱/모바일), 접근성(키보드·스크린리더 기본)

### ❌ 미포함 (실데이터·시스템 필요 → [03 문서](./03-integration-ellis.md))
- 실시간 재고·티타임·가격 API (현재 목데이터 고정)
- 결제(PG) — 체크아웃은 UI 시뮬레이션 (애드온 합산액 포함하나 실결제 아님)
- 회원/인증/마이페이지·**포인트 적립/사용** 연동 (위시·비교·최근검색은 localStorage)
- 콘텐츠 다국어 번역(현재 UI만 다국어, 본문/상품명은 한국어·영문 혼재)
- 자사 보유/라이선스 실사진 (현재 CC 스톡 풀 — 일부 골프 무관 이미지 있음)

## 4. 의사결정 필요 (기획팀)

상세는 [04 문서 §로드맵/의사결정](./04-design-qa-roadmap.md) 참조. 핵심만:

1. **상품 채택 여부** — 골프텔 카테고리를 정식 상품으로 진행할지
2. **타깃 확정** — ‘30·40대 여성 힐링 골프’ 핵심 유지 + 메시지 확장 범위(커플·시니어·동호회)
3. **재고/티타임 소싱 모델** — 직접 계약 vs 제휴, 티타임 실시간/요청형 여부
4. **가격 정책** — 1인가 + 현지 결제(카트/캐디) 표기·정산, **조인/단독·소인원 할증률**, 비골퍼 요금, **애드온 수수료/정산**
5. **포인트 정책** — 오마이 골프 포인트 적립률/사용 정책, 본사 마일리지 통합 여부
6. **ELLIS 골프텔 스키마 신설** 범위 — [03 문서]의 필드 매핑 검토
7. **브랜드/도메인** — OHMYGOLF vs 오마이트립 내 서브카테고리(현재 후자로 통합 중)
