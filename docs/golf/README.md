## 2. 제품 개요

**무엇**: 숙박(골프텔) + 라운드(티타임)를 한 번에 예약하는 **Stay & Play 패키지** 상품. 오마이트립 본 서비스의 새 카테고리로 검토 중.

**왜 프로토타입 먼저**: 자사 시스템(ELLIS)에 골프텔 상품 공간이 아직 없어, 화면·플로우·데이터 구조를 **프론트로 먼저 검증**하고 방향성을 판단하기 위함.

**벤치마크**: Golfbreaks · golfscape · Your Golf Travel · monkeytravel(골프텔 상세 구조 참조).

**핵심 가치 제안**
1. 숙박·라운드·티타임·이동을 **1인당 투명 가격**으로 패키지화 (현장 추가 결제 최소화)
2. 골프장 상세 정보(스코어카드·현지요금·플레이 조건)를 **패키지 안에서** 제공 → 페이지 이동 없이 예약
3. 콘텐츠(골프 여행 이야기) → 관련 패키지 CTA로 **읽다가 바로 예약**

## 3. 범위 (현재 프로토타입에 포함/미포함)

### ✅ 포함 (동작하는 프로토타입)
- 검색(목적지 팝오버·듀얼 캘린더·인원) → 결과(필터/정렬/지도) → 상세 → 예약 위저드 → 완료 → 마이트립
- 골프장 상세 정보(인라인), 사진 여행일정, 티타임 선택·검증, 비교(최대 3), 위시리스트, 맞춤 견적
- 통화 5종·언어 4종(UI), 골프 여행 이야기 블로그
- 반응형(데스크톱/모바일), 접근성(키보드·스크린리더 기본)

### ❌ 미포함 (실데이터·시스템 필요 → [03 문서](./03-integration-ellis.md))
- 실시간 재고·티타임·가격 API (현재 목데이터 고정)
- 결제(PG) — 체크아웃은 UI 시뮬레이션
- 회원/인증/마이페이지 연동 (위시·비교·최근검색은 localStorage)
- 콘텐츠 다국어 번역(현재 UI만 다국어, 본문/상품명은 한국어·영문 혼재)
- 자사 보유/라이선스 실사진 (현재 CC 스톡 풀 — 일부 골프 무관 이미지 있음)

## 4. 의사결정 필요 (기획팀)

상세는 [04 문서 §로드맵/의사결정](./04-design-qa-roadmap.md) 참조. 핵심만:

1. **상품 채택 여부** — 골프텔 카테고리를 정식 상품으로 진행할지
2. **재고/티타임 소싱 모델** — 직접 계약 vs 제휴(예: monkeytravel형 현지 파트너), 티타임 실시간/요청형 여부
3. **가격 정책** — 1인당 패키지가 + 현지 결제 항목(카트/캐디)의 표기·정산 방식
4. **ELLIS 골프텔 스키마 신설** 범위 — [03 문서]의 필드 매핑 검토
5. **브랜드/도메인** — OHMYGOLF vs 오마이트립 내 서브카테고리
